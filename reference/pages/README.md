# Références pour les pages sans design Figma

**Méthode conseillée : dans le Figma.** Une page « Références », un frame par page nommé `Section / Page` (ex. `Ressources / Typographie`), avec dedans les captures, les notes et les liens.

**Autre possibilité : ici,** un dossier par page. Dépose dedans tout ce qui aide à concevoir la page :

- **Images** : captures d'écran de sites ou d'outils que tu aimes, croquis, photos (PNG, JPG, PDF…)
- **Liens** : colle-les dans un fichier `liens.md` du dossier, une ligne par lien, avec un mot sur ce qui te plaît
- **Contenu** : textes, listes de rubriques, exemples réels (logos, couleurs…)

| Dossier | Page |
|---|---|
| `ressources-logos` | Ressources › Logos |
| `ressources-couleurs` | Ressources › Couleurs |
| `ressources-typographies` | Ressources › Typographies |
| `ressources-icones` | Ressources › Icônes |
| `ressources-patterns` | Ressources › Patterns |
| `ressources-inspiration` | Ressources › Inspiration |
| `layout-editor` | Layout editor (ancien « Design libre ») |
| `profil-editeur` | Mode éditeur, mot de passe, menu Réglages |
| `feedback` | Feedback |
| `autres` | Tout le reste |

Les pages conçues à partir de ces références suivent le style du Figma (couleurs, typos, composants) et sont validées avant d'être codées.
